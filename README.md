## 프로젝트 개요
텍사스 홀덤 포커에 관한 퀴즈를 풀 수 있는 터미널 기반 퀴즈 게임입니다.
퀴즈 풀기, 추가, 삭제, 점수 확인 기능을 제공하며 게임 기록이 저장됩니다.

## 퀴즈 주제 선정 이유
평소 텍사스 홀덤을 즐겨 하다 보니 규칙과 용어에 익숙해 퀴즈 문제를 직접 설계하기 용이했습니다.
단순한 예제보다 실제로 관심 있는 주제로 만들면 더 의미 있는 학습이 될 것이라 판단했습니다.

## 실행 방법
```bash
python3 main.py
```

## 기능 목록
- 퀴즈 풀기: 랜덤 출제, 문제 수 선택, 힌트 기능
- 퀴즈 추가: 새로운 퀴즈 등록
- 퀴즈 목록: 등록된 퀴즈 목록 확인
- 점수 확인: 최고 점수 및 게임 기록 히스토리
- 퀴즈 삭제: 등록된 퀴즈 삭제
- 기록 초기화: 모든 데이터 초기화

## 파일 구조
```
1-2-quiz_game/
├── main.py       # 프로그램 진입점, 메뉴 처리
├── game.py       # QuizGame 클래스, 게임 로직
├── quiz.py       # Quiz 클래스, 기본 퀴즈 데이터
├── state.json    # 퀴즈 데이터 및 게임 기록 저장
├── .gitignore
└── README.md
```

## 데이터 파일 설명 (state.json)
- **경로**: 프로젝트 루트의 `state.json`
- **역할**: 퀴즈 목록, 최고 점수, 게임 기록 히스토리를 저장
- **인코딩**: UTF-8
- **스키마**:
```json
{
    "quizzes": [
        {
            "question": "문제 텍스트",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 1,
            "hint": "힌트 텍스트"
        }
    ],
    "best_score": 0,
    "history": [
        {
            "date": "2026-04-06 12:00:00",
            "count": 5,
            "score": 4.5
        }
    ]
}
```
